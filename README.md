# SauceDemo-automation
Playwright automation of Saucedemo website

# Technologies
Playwright
Javascript 
Node.js

Github
Vscode


# Tests Automated
Login
Product sort
Add to cart
Checkout
Navigation

# Installation step
npm init playwright@latest

# Steps to run

npx playwright test ./tests/spec.js file (headless mode)
npx playwright test ./tests/spec.js file --headed  (headed mode)
